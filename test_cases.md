# Kumbh Suraksha – Test Cases

## Testing Objective
To check the basic functionality of the Kumbh Suraksha prototype.

| Test Case | Test Description | Expected Result |
|---|---|---|
| TC01 | Open the Home page | Home page loads successfully |
| TC02 | Navigate between pages | Selected page opens correctly |
| TC03 | Open Crowd Monitoring | Crowd-related information is displayed |
| TC04 | Open the Map page | Map interface is displayed |
| TC05 | Enter valid prediction inputs | Prediction result is displayed |
| TC06 | Open Analytics | Analytics information is displayed |
| TC07 | Open Emergency Alerts | Emergency alert interface is displayed |
| TC08 | Enter invalid prediction inputs | Input is rejected or an error is handled |

## Note
These are planned test cases. Actual results must be recorded after testing the prototype. The system uses sample data and is not intended for real emergency decisions.
